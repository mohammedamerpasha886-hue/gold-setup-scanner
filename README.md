# MyApp

Welcome to **MyApp**, a persistent, AI-provider-independent coding workspace.

## About This Project
This repository is configured as a persistent workspace designed to be developed collaboratively across different AI coding models, providers, and agents (such as Gemini, OpenRouter models, and custom coding agents) without losing project context.

## Project Structure & Documentation
- **`AI_CONTEXT.md`**: Primary persistent handoff document and AI agent guidelines.
- **`ARCHITECTURE.md`**: High-level system design and architectural decisions.
- **`TODO.md`**: Active task backlog and roadmap.
- **`DECISIONS.md`**: Architecture Decision Records (ADRs).
- **`CHANGELOG.md`**: Chronological release and change history.

## Getting Started
